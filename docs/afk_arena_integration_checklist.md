# 《剑与远征经典服》接入清单

## 设备与运行环境

- 设备类型：安卓真机或模拟器
- ADB 设备标识
- 屏幕分辨率
- Android 版本
- USB 调试或模拟器 ADB 是否已经可用

## 游戏运行环境

- 账号所在区服
- 游戏 UI 语言
- 账号是否能保持登录状态
- 登录后是否会出现公告或活动弹窗
- 是否存在会打断首页流程的限时活动页面

## 需要提供的截图

- 启动页
- 首页
- 邮箱页
- 任务页
- 日常任务页签
- 挂机奖励弹窗
- 领取奖励过程中可能出现的确认弹窗

## 后续检测所需素材

- 稳定按钮的模板裁剪图
- 用于页面识别的 OCR 关键词
- 容易误判按钮的负样本
- 不同分辨率下的坐标锚点

## 建议加入的安全控制

- 正式点击前的 dry-run 模式
- 每个步骤独立超时
- 识别到未知页面时立即停止
- 手动暂停热键
- 按账号记录执行日志
